# One companion, existing owners

ARCHi is one native macOS app with bounded helpers. Native local records are authoritative. KIN's Core Seed and body presentation are one continuing individual; a different appearance or interface does not create another identity or permission owner. This describes source responsibilities, not release qualification. See [one-app operation](one-app-system.md) and the [native authority and lineage map](native-authority-and-lineage.md).

## Native state and working context

`CompanionStore` coordinates assistance, confirmed preferences, working copies, placement and presentation. `CompanionProfiles` resolves the selected individual. `NativePreferenceDocument` retains preferences, kept lessons, personal context and collected items; `ReadingSourceLibrary` owns retained sources, compiled pages and reviewed relationships. `TokenStewardStore` records task provenance and observations, while `DocumentWorkJournal` owns document revisions and reviewed outcomes. These are distinct domain owners, with no global transaction spanning every file.

Qwen, optional Codex and deliberate Compare retain separate requests and receipts. Native admission checks, captured context references and cancellation fences govern the current answer. First-run delivery defaults to Local only; an explicitly selected fallback route can permit an eligible external attempt. Private local context stays outside the ordinary external lane, and captured window text requires an allowance for its exact copy. See [native model routing](native-qwen.md).

Work together operates on a deliberately shared text copy. The pointing flow identifies a window from metadata; explicit Read captures permitted Accessibility text or local OCR. `DesktopInterestSession` rejects stale results and presents the snapshot for review. Adopting it does not continuously synchronize the external app. Selection, proposals and Apply bind to the working-copy revision; Undo and export affect that copy. Reading or adopting alone invokes no inference, keeps no lesson and awards no development. Captured OCR images are not a camera or image-understanding feature.

Memory map and graph views project records and source relationships from their existing owners. Inspection, filtering, animation and export do not create another memory store or prove a model used a source correctly. Historical task references cannot restore withdrawn content. Reviewed outcomes, method reuse and saved development retain their separate admission rules. Recovery controls do not make temporary replies or unsaved working copies durable.

## Unity and Arena

[`UnityPresentationConnection`](../desktop/Sources/ARCHiDesktop/UnityPresentationConnection.swift) sends a bounded native appearance/session snapshot to the Unity helper. Acknowledgments bind to the session, revision and supported appearance fields. Prompts, replies, documents, lessons and evolution receipts are excluded from that snapshot. Unity presents accepted companion state and reports bounded practice observations; it cannot write native memory or commit saved growth.

Arena is available through [`ArenaEntryAction`](../desktop/Sources/ARCHiDesktop/ArenaEntry.swift). Browsing the page launches nothing; Play Arena explicitly starts or focuses a compatible helper. Local roster practice can run without creating a saved companion. Solo practice and two people sharing one Mac are supported in the source. Guest ECHO and paired history are session-only. Practice grants no saved growth, Marketplace rewards or canonical item effects. Network multiplayer is not implemented. Build and interaction evidence must still be checked separately; see [Arena access](developer-access-protocol.md#arena-enter-and-join-a-local-game) and [Unity source](../unity/ARCHi/README.md).

Arena's [ARCHi Trials](native-arena-arc.md) activity uses the existing native grid/ARC3 owners. It does not direct Unity combat. Imported tasks, synthetic samples, unscored predictions and checked results retain their provenance and limits; they do not establish official benchmark scores. Retained TypeScript Journey/battle reducers, Relay and hosted readback paths remain separate domain code. Their historical visibility settings do not mean the current Unity Arena is disabled.

Acquisition, download, installation and equip are distinct actions. Current recipe registration uses exact bundled matches; the canonical-effect list is empty. Publisher declarations and recorded acquisition identifiers do not verify legal title, identity, scarcity or payment.

Local Ollama/Qwen, optional representation workers and optional artwork tools serve native owners. The creator service is a loopback development service; Internet hosting, payments, signed editions and ownership transfer are not supplied here. WikiOS is a linked interface. A future authenticated plugin must resolve an explicit profile and route changes through native operations with their revision and sharing checks. No plugin connection, cross-device synchronization or iPhone feature parity is established by this architecture.
