## Working with the map

- **Memory** shows retained sources, authored knowledge-page records, kept lessons, saved methods, and their recorded connections. The companion is a visual anchor, not another remembered fact.
- **All activity** includes request receipts, temporary context, outcomes, usage and ARC evidence. Those records are not counted as new memories.
- Select a particle or use **List** to inspect status, source version and recorded backlinks. Knowledge pages still open their existing page inspector. Retained-source actions open the memory library rather than an unrelated shared working document. View options retains Constellation, Radial and Flow alongside the Particles default.
- **Focus connections** narrows the map to a selected record and its direct connections. Following a related record while focused moves to that record's neighborhood; **Back** restores the preceding focus, and **All records** clears focus. Particle focus frames the neighborhood's existing anchors. Search and record-type filtering hide nodes without moving those anchors or reframing the focus. Card layouts also preserve remaining positions through filtering; explicit focus selects a smaller layout neighborhood.
- **Ask ARCHi** opens the existing native question workspace beside the map. It shares the same question draft, route, attachments and replies. Closing and reopening this pane preserves the draft and map state; selecting a node alone does not attach it.
- **Ask about this** explicitly attaches the exact current reviewed knowledge-page version to local chat, after rechecking its source availability. Historical, changed or unavailable versions are not silently replaced. The existing four-page limit and draft guards still apply, with attachment failures shown in the map. Review the attached context and question before **Send**; opening or attaching sends nothing.
- **Showcase** hides secondary controls and gives the canvas more room. Selecting a record reveals its inspector. **Exit showcase** or Escape restores controls. List and Fit remain accessible; active filters stay visible and can be cleared.
- Showcase is a local presentation mode. It displays the current profile's real titles and records. It does not anonymize them, create a public link, export a demo or add sample memories.

Home displays retained source-copy counts, latest page-record counts (including drafts and withdrawn pages), and valid non-expired kept lessons. Open a record to inspect its state. Removed source versions remain marked as unavailable references; they do not inflate the retained-source count. The small Home preview is static and bounded, with no model work or constant animation. The full map respects reduced motion.

## From a concept to useful work

Select a current reviewed **Concept** and choose **Create a method…**. The existing method editor captures an explicit title, instruction and checks against that exact concept version. Saving creates an authored candidate, selects its real map node and retains its source connection. Saving, animation and inspection do not establish usefulness. If the source changes while editing, the draft stays visible and copyable but Save is blocked.

**Inspect this method version → Try in document work** carries the exact method into the existing Work together workspace. Select a live passage and choose Rewrite or Shorten there; old spatial selection is invalidated on navigation. **Preview for selected passage…** shows the instruction and any replacement of an existing draft before preparation. Send, checked Apply and the owner's Helpful/Needs correction review remain separate actions. Historical, withdrawn or stale-source methods remain inspectable but cannot prepare new work. The handoff is transient and clears when data owners change.

The map's **Work** popover exposes existing document outcomes, review queue and saved methods. Document work and method follow-through can return to the exact method version in the map. Leaving document work currently cancels an unapplied proposal; inspect and apply or preserve its text before leaving. The retained cancellation is not a usefulness judgment. Making that review handoff persistent is still a UX gap.
