# Native Alpha source checkpoint — 25 September 2026

This checkpoint updates native working-document, local-model, recovery and representation integration source on the existing ARCHi draft branch. It is a source-development checkpoint, not a Beta release, a notarized installer or a claim that the full Hampton research stack is validated.

## Daily work

Work together binds a document task to its current working copy. Assistance proposes a revision; native checks, explicit Apply, readback and an outcome review govern whether that revision becomes retained experience. Saved methods preserve their particular versions and evidence references. A current-edit card connects the applied edit to feedback and a method starter. Kept reading copies remain source material selected for specific work, not a second authoritative memory store.

The native Hampton controller adjusts retain, expand, repair and stop decisions from bounded task signals. This does not establish that every archived numerical Q2E component is connected or that a universal intelligence measure has been validated. ARC remains an active reasoning/tool subsystem. No puzzle benchmark is implied by this checkpoint.

## Recovery

Saved & this visit → Backup & restore creates a v2 archive for the selected profile's preferences, development, document-work receipts, method versions and kept reading sources. The last category can include source text, so the archive is private material. A successful restore replaces and reloads that coherent file set. An interrupted restore is recovered before document owners load; conflicting state blocks writes.

An older two-file archive is accepted only when no document-work, method or reading-source sidecars exist at the destination. A preview is bound to current disk state. Stale previews, pending mutation receipts and unsafe path aliases do not permit replacement. Restoring clears obsolete answers, source selections, prepared methods and Undo while retaining the current visit's typed draft and working-copy bytes.

Backups cover the selected profile, not every companion or the profile registry. They exclude usage/cost accounting, ARC evidence/sessions, device model choices, chat, unsaved draft storage, original documents, working-copy bytes, app bundles, model weights and artwork. Recovery never invokes a model or repeats an external action.

## Build and presentation limits

Build the native source with `swift build --package-path desktop`. This does not install or launch ARCHi. The packaging script is separate and requires a qualified existing Unity player; `--stage-only` avoids replacing the installed app. Optional representation packaging accepts only a pinned local runtime. No model download or reader calibration happens as part of a normal native build.

This source update intentionally keeps the draft branch's existing image and Unity asset bytes. Eight native image hash bindings carry forward its metadata-sanitized PNGs; their non-metadata image payloads match the current local originals. No new artwork or redistribution grant is added.

The newer Light ball, Proto, Liminal and Garnet portraits are absent from this source distribution. Native fallback rendering remains available, but this checkout does not reproduce every installed visual. Checks that explicitly require those optional portraits are not qualified by the compile-only source check. The current Unity source/player and ARC3-to-world action bridge are not upgraded here.

The full local developer ledger, personal profiles, papers, chat notes, calibration data and generated outputs are excluded. Broader workflow acceptance, another-Mac installation, accessibility, signing/notarization and final release review remain separate gates.
