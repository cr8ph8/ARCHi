# Ask ARCHi — one conversation, familiar entry points

29 September 2026. Ask ARCHi is the shared desktop conversation destination. ARCHi is the product; Liminal, KIN and other chosen companion names remain the individual's identity.

## What changed

Home, the sidebar, Window menu, menu-bar shortcut, companion menu, attached bubble and full workspace use the same Ask ARCHi wording. A single presentation-only definition supplies the title and companion subtitle. Existing section values, accessibility action IDs, keyboard shortcuts and saved settings remain intact.

The full workspace presents a concise purpose, an attached companion and two optional starting points: Memory map and Work together. These actions navigate existing owners. They neither select sources for a request nor start a model call. Actual replies, errors and task results remain visible. The composer stays anchored with the destination and Send/Stop controls.

The bubble retains immediate route and source-sharing notices; supplementary reply settings, lessons and budget are under Reply options. With explicitly selected knowledge pages, it correctly states that their passages stay with local Qwen and the loaded shared document is not sent. With a deliberately shared document, it still discloses the full-copy boundary.

The profile card presents identity, confirmed local context, reference-only details and open details separately. Source attribution survives edits exactly as entered; invalid or stale changes remain blocked by the existing preference owner. Unknowns stay unknown.

## Shared system ownership

Both Ask ARCHi surfaces use the same CompanionStore draft, route, request, cancellation, reply and memory state. Opening a larger workspace or closing a bubble does not create another conversation or send a draft. This change adds no provider, permission, model download or automatic memory write.

Local Qwen, the explicitly selected bounded Codex fallback and task-specific representation measurements retain their distinct scopes. See [current routing](native-automatic-assistance.md) and [current measurement scope](native-qwen-representation.md).
