## Revision fidelity

Only the selected passage contributes. The inventory is request-scoped reference data, not new saved memory or instructions extracted from a document.

This guidance does not establish semantic preservation. Native checks still reject digit-to-word changes and changed literal links. A model reply remains a proposal; the user reviews its meaning and usefulness.
