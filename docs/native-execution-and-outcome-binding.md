# Shared execution and reviewed outcome binding

25 September 2026. ARCHi chooses an existing executor once and carries reviewed evidence through the existing native document owner. This is a runtime integration increment, not a new model or another task store.

## Execution choice

`AssistantExecutionSelection` is used by the composer, call-limit disclosure, readiness and Send. Explicit native ARC commands retain their existing handlers; ordinary text, prepared document procedures and pointing use assistance. Invalid commands execute nothing. ARC3 Open, Stop and Explore explain their distinct actions; inspecting the interface starts no gameplay.

`LocalExpertPolicy` supplies the same compact/reasoning decision for preview and the request. Source material, selected passages, revisions, reading and representation measurements require the reasoning model. Auto uses Compact only for the existing exact greeting/thanks list. Its recovery ceiling is shown only for eligible compact work. Context calls are a separate optional ceiling, not a claim that every request consumes them.

External access still follows the selected route and exact-copy permission. Kept reading sources and their derived context stay local. Measurements stay local. Pointing readiness evaluates its assistant request even if the unsent draft happens to contain a native command.

## Q2E evidence in everyday work

The native controller keeps its five declared coordinates: support, coverage pressure, verifier pressure, alternative coverage and remaining resources. It does not relabel those coordinates as model activations or general intelligence dimensions.

The document adapter reconciles journal records before selecting the latest eight matching attempts. Each frozen input retains its request, provider, exact source/selection, checks, review event, procedure version, original decision reference and a digest of the reconciled metadata. Applied and explicitly reviewed Helpful outcomes count as support; attributable corrections and mechanically blocked checks count as correction. Unreviewed results and transport failures remain unknown. Conflicting copies or malformed attribution stop the consumer rather than becoming a smaller successful sample.

Version 2 decisions name their coordinate schema and retain a bounded prior-state reference. Validation checks the policy result, the exact effective difference `q_next - q_previous`, and agreement between outcome counts and their frozen bindings. The initial zero reference is explicit; it is not presented as an observed predecessor. Legacy v1 history remains readable without rewriting it or fabricating lineage.

Send freezes the decision. Immediately before provider generation, ARCHi rebuilds it from current history. A changed review or method stops the request; the user can send again with the current evidence. Other provider lanes in that same request are excluded from the historical comparison so Compare does not invalidate itself.

The existing Apply, feedback, method library, usage ledger and development owners remain responsible for their changes. A controller decision does not apply an edit, award growth, establish truth or train model weights. Reading and ARC3 use the common v2 state-transition record; this new reviewed-document adapter is specific to revision work.

## Qualification boundary

Focused checks use synthetic journal records and mock clients: command/prepared-work separation, protected material, call ceilings, feedback correction, duplicate handling, schema/delta tampering, legacy read compatibility, delayed connection and same-request lanes. No puzzle campaign, live model generation, API request or scientific efficacy comparison is part of this increment. Build/install identities and source publication are recorded separately in the delivery evidence.

The broader numerical controller still needs a declared domain adapter with compatible measurements, targets, gains, coupling and potential. An installed base model does not qualify a representation reader. These remain separate from the operational five-pressure controller described here.
