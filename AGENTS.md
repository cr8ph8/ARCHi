# ARCHi contribution context

Read CONTRIBUTING.md, docs/source-ownership.md and the affected native, Unity or iPhone owner contract. This repository is a curated source distribution. Private profiles, model weights, withheld artwork and original research attachments are not part of it.

On the authoring Mac, change the main ARCHi workspace and deliberately promote reviewed source here. Do not maintain competing feature implementations in this export. On an independent developer checkout, work normally in a focused branch and preserve existing state owners.

Run focused checks and verify SOURCE_SHA256SUMS coverage. Do not treat a build, graph display, provider answer or visual motion as permission to store learning. No blanket benchmark, live-provider call, app installation or private-profile access is required for a code review.
