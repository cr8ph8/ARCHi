# ARCHi Unity presentation source

Unity 6000.5.4f1 (d550df8bd089), the macOS standalone module, Built-in Render Pipeline and the project package manifest are the source prerequisites. Native ARCHi remains the owner of identity, private assistance, saved development and installed item records. This Unity project presents companion state, the selected Seed appearance and explicitly entered local Arena practice. Practice does not commit native development or grant Marketplace recipes canonical effects.

From the source root use `bash script/build_unity_port.sh` only after source writers finish and no second Editor has this project open. The helper builds a development player and writes a receipt under output; it does not install or launch the player. A player build must be followed by native handoff, stop/reopen, stale-state, keyboard/VoiceOver, rendering and ordinary-use checks.

The separate Editor entry point `EvolutionFoundationValidation.Validate` always verifies the bundled Proto and KIN FBX bytes against their included provenance, along with imported geometry and working evolution rules. It is available through Unity's `-executeMethod` argument. The receipt explicitly reports `authoringParityStatus: unavailable` when the private `desktop/ArtSources` copies are absent, as they are in this source packet. If an authored copy is present, a mismatched hash fails validation. `EvolutionFoundationValidation.ValidateAuthoring` is the strict local authoring check: it requires both original copies and fails when they are absent. A portable runtime pass does not claim private authoring parity or redistribution authority.

Keep Assets, its FBX rigs, all associated .meta files, Packages and ProjectSettings. Exclude Library, Temp, Logs, UserSettings and build products. Coplay 10.0.0 is optional embedded Editor tooling with its own retained MIT license. Engine/editor packages are external prerequisites.

See the root ASSET_ATTRIBUTION.md and docs/ALPHA_VALIDATION.md for metadata, redistribution and acceptance boundaries. No source-ready or release claim follows from an imported model or a successful Editor build.
