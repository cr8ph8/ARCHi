# ARCHi

ARCHi is a native companion for working with local models, source-linked memory and reviewed outcomes. Its memory map connects real records to their sources, versions, relationships and methods. Ask ARCHi and Work together use the same native owners; Liminal, Companion room and Arena express or inspect that state.

**Status: supervised local alpha development.** The public repository is a code-review candidate, not a notarized app or beta release. Some artwork is withheld pending redistribution review. A compiled source snapshot is separate from the installed desktop and iPhone versions. [Current source ownership](docs/source-ownership.md) · [Delivery evidence and limits](docs/method-memory-integration-2026-10-02.md).

## What is here

- **Memory and methods:** inspect exact source versions, typed relationships, reviewed lessons and method history; explicitly select a method for document work.
- **Assistance:** local Qwen, with Local only as the initial route and an explicitly selected bounded Codex fallback. A proposed answer or edit remains separate from Apply and outcome review.
- **Hampton adaptation:** bounded task-state updates with declared inputs, provenance and runtime consumers. Reuse and feedback do not train the language model or establish whole-stack efficacy.
- **Companion and Arena:** native presentation plus a Unity renderer for local practice and two seats on one Mac. Presentation, practice and Marketplace recipes do not grant canonical learning or battle effects.
- **Local integration:** exact-source WikiOS task exchange, local creator-service code and retained Field source. Remote multiplayer, production commerce and automatic phone/desktop continuity remain open.

The desktop entry point is the existing `/Applications/ARCHi.app`. [Use the app, Marketplace and Arena](docs/developer-access-protocol.md) · [One-app recovery](docs/one-app-system.md) · [Native ownership](docs/native-authority-and-lineage.md).

## Build and contribute

For the native target, use macOS 14+ and a Swift 6 toolchain:

```sh
swift build --package-path desktop
```

This compiles source without installing or launching. The guarded installer requires a qualified Unity helper and retains rollback; follow the [developer protocol](docs/developer-access-protocol.md#build-or-update-the-one-app). Missing artwork can still block artwork-dependent checks and full presentation reproduction.

For retained TypeScript source, use the pinned npm lock and Node 24:

```sh
npm ci
npm run build
```

Liminal phone portraits are optional source assets. An omitted image disables its portrait choice and leaves the existing presence renderer available. No replacement artwork is generated by the build.

Read [CONTRIBUTING](CONTRIBUTING.md), [architecture](docs/ARCHITECTURE.md) and [source ownership](docs/source-ownership.md). Make focused changes in the main authoring workspace, promote reviewed source into the existing delivery checkout and run the parity/manifest checks. An independent contributor can use a normal focused branch of this source repository. Do not publish private profiles, raw research attachments, original artwork or model weights.
